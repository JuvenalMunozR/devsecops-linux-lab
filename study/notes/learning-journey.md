# DevSecOps Linux Lab - Learning Journey

## Purpose

Este directorio contiene mis apuntes personales, reflexiones técnicas y resúmenes de aprendizaje durante el desarrollo del laboratorio.

No forma parte de la documentación pública del proyecto.

Su objetivo es consolidar el conocimiento adquirido como Ingeniero en formación.

---

## Mentor Model

Este laboratorio se desarrolla bajo una metodología de mentoría técnica.

Roles:

- Senior DevSecOps & Security Engineer (Mentor IA)
- Junior Security Engineer (Aprendiz)

Cada laboratorio busca resolver un problema real antes de introducir herramientas o comandos.

---

## Learning Principles

1. Comprender antes de ejecutar.
2. Resolver problemas antes de aprender herramientas.
3. Documentar decisiones técnicas.
4. Aprender haciendo.
5. Mantener evidencia de cada laboratorio.
6. Construir un portafolio profesional, no solo completar ejercicios.

---

## Repository Mission

Construir un entorno Linux profesional que sirva como base para futuros laboratorios de DevSecOps y Ciberseguridad.
