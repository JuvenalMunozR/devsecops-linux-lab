# Module 08 - Bash Scripting Fundamentals

## Objective

Learn the fundamentals of Bash scripting to automate operational, administration, and DevSecOps-related tasks in Linux environments.

---

## Topics Covered

* Variables
* Script Arguments
* Conditional Statements
* Functions
* Wildcards
* Argument Validation
* File Validation
* Directory Validation
* Logging
* Basic Error Handling

---

## Scripts Developed

| Script             | Purpose                                              |
| ------------------ | ---------------------------------------------------- |
| variables.sh       | Demonstrates Bash variables and command substitution |
| arguments.sh       | Demonstrates command-line arguments                  |
| if-statement.sh    | Demonstrates conditional execution                   |
| functions.sh       | Demonstrates reusable functions                      |
| validation.sh      | Validates user input arguments                       |
| error-handling.sh  | Validates file existence before execution            |
| logging.sh         | Generates execution logs                             |
| directory-check.sh | Validates directory existence                        |

---

## Skills Acquired

* Bash scripting fundamentals
* Input validation
* Error handling
* Logging and traceability
* Function-based code organization
* File and directory verification
* Linux automation concepts

## DevSecOps Relevance

Bash scripting is a foundational skill for DevOps and DevSecOps engineers. These concepts are commonly used in:

* System administration
* Infrastructure automation

* Monitoring
* CI/CD pipelines
