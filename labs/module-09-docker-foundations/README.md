# Module 09 - Docker Foundations

## Objective

Learn the fundamentals of Docker and containerized environments.

## Topics Covered

* Docker Engine
* Docker Images
* Docker Containers
* Container Lifecycle
* Docker Volumes
* Data Persistence
* Dockerfile Fundamentals

## Commands Practiced

```bash
docker pull
docker images
docker run
docker start
docker exec
docker ps
docker volume create
docker volume ls
docker build
```

## Key Learnings

* Images are templates used to create containers.
* Containers are isolated runtime instances.
* Volumes provide persistent storage.
* Dockerfiles allow reproducible image creation.
* Docker supports portable and consistent deployments.
