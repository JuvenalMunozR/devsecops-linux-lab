# Module 11 - Docker Compose Fundamentals

## Objective

Learn the fundamentals of Docker Compose to deploy and manage containerized applications using a declarative configuration file.

---

## Concepts Covered

- Docker Compose
- compose.yaml
- Services
- Port publishing
- Application lifecycle
- Declarative infrastructure

---

## Labs Completed

### Lab 11.01

Created the first `compose.yaml` file.

### Lab 11.02

Deployed an application using:

```bash
docker compose up -d
```

### Lab 11.03

Inspected the application status.

Commands practiced:

- docker compose ps
- docker compose images
- docker compose ls

### Lab 11.04

Managed the application lifecycle using:

- docker compose stop
- docker compose up -d
- docker compose down
