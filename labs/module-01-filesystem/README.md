# Module 01 - Linux Filesystem Foundations

## Objective

Understand the Linux filesystem structure, navigation commands, and the location of critical system directories used in administration, troubleshooting, and DevSecOps environments.

---

## Prerequisites

- Ubuntu (WSL2 or native)
- Basic terminal usage
- Git installed

---

## Topics Covered

* Linux filesystem hierarchy
* Directory navigation
* File and directory management
* System structure exploration
* Operational troubleshooting basics

---

## Commands Practiced

```bash
pwd
ls
ls -la
cd
tree
mkdir
touch
cat
```

---

## Key Directories Explored

| Directory | Purpose                        |
| --------- | ------------------------------ |
| /         | Root filesystem                |
| /home     | User home directories          |
| /etc      | System configuration files     |
| /var      | Logs and variable data         |
| /proc     | Process and kernel information |
| /tmp      | Temporary files                |

---

## DevSecOps Relevance

Understanding the Linux filesystem is essential for:

* Log analysis
* Security investigations
* Docker volume management
* Configuration management
* Troubleshooting
* System hardening

A strong filesystem foundation is required before working with containers, CI/CD pipelines, and cloud infrastructure.

---

## Expected Deliverables

By completing this laboratory you should be able to:

- Navigate the Linux filesystem confidently.
- Identify the purpose of critical system directories.
- Manage files and directories from the command line.
- Understand the relationship between filesystem organization and system administration.

---

## Laboratory Outcome

Successfully explored the Linux filesystem hierarchy and practiced navigation, file management, and system structure analysis.
