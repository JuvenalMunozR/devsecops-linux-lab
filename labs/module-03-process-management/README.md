# Module 03 - Process Management

## Objective

Understand how Linux manages processes, background jobs, and system services to support operational monitoring, troubleshooting, and secure system administration.

---

## Topics Covered

* Process identification
* Background jobs
* Process monitoring
* Process termination
* Linux services
* Systemd fundamentals

---

## Commands Practiced

```bash
sleep
jobs
ps aux
grep
kill
systemctl
```

---

## Concepts Learned

### Process ID (PID)

Each running process in Linux is assigned a unique Process Identifier (PID).

### Background Jobs

Processes can run in the background, allowing users to continue working in the terminal.

### Process Monitoring

Linux provides tools to inspect running processes, resource usage, and execution status.

### Service Management

System services are managed through systemd and can be inspected using systemctl.

---

## DevSecOps Relevance

Process management is essential for:

* Operational troubleshooting
* Service monitoring
* Incident response
* Container runtime understanding
* Docker process analysis
* System hardening

Understanding process behavior helps identify abnormal activity and supports security investigations.
