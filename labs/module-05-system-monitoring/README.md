# Module 05 - System Monitoring

## Objective

Understand how to monitor Linux system health, resource consumption, and operational status using native monitoring tools.

---

## Topics Covered

* System uptime
* CPU utilization
* Memory utilization
* Swap usage
* Disk usage
* Process monitoring
* Resource consumption analysis

---

## Commands Practiced

```bash
uptime
free -h
df -h
du -sh
top
ps aux
```

---

## Concepts Learned

### Uptime

Measures system availability and load averages.

### Memory Monitoring

Evaluates RAM consumption and available memory.

### Swap

Provides additional virtual memory when physical RAM becomes constrained.

### Disk Monitoring

Tracks storage utilization and available capacity.

### Process Monitoring

Identifies resource-intensive processes and operational bottlenecks.
