# Module 03 - Process Management

## Objective

Understand how Linux creates, manages and terminates processes, and how process control supports system administration, troubleshooting and DevSecOps operations.

---

## Learning Outcomes

After completing this module you will be able to:

- Identify running processes.
- Monitor system resource consumption.
- Control foreground and background jobs.
- Send signals to processes.
- Diagnose abnormal process behavior.

---

## Topics

- Process lifecycle
- PID and PPID
- Process states
- Foreground and background jobs
- Signals
- Process priority
- Monitoring tools

## Security Perspective

Process monitoring allows administrators to detect abnormal executions, malicious software, resource exhaustion and unauthorized activities.
