# Module 02 - Users and Permissions

## Objective

Understand Linux identity management, ownership, permissions and privilege delegation as the foundation for secure system administration.

---

## Learning Outcomes

After completing this module you will be able to:

- Understand Linux users and groups.
- Interpret UID and GID values.
- Manage file ownership.
- Apply Linux permission models.
- Use sudo securely.
- Apply the Principle of Least Privilege.

---

## Topics

- User Accounts
- Groups
- UID and GID
- Ownership
- Permissions (rwx)
- chmod
- chown
- chgrp
- sudo
- Least Privilege

---

## Security Perspective

Incorrect permissions are one of the most common causes of privilege escalation and information disclosure.

A correct permission model reduces the attack surface of Linux systems and containers.
