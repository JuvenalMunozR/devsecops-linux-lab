# Module 09 - Docker Foundations

## Objective

Understand container technology and Docker fundamentals as the basis for modern DevSecOps platforms.

---

## Learning Outcomes

After completing this module you will be able to:

- Understand container architecture.
- Differentiate containers from virtual machines.
- Build Docker images.
- Run and manage containers.
- Persist data using volumes.
- Understand Docker networking fundamentals.

---

## Topics

- Containers
- Images
- Docker Engine
- Dockerfile
- Volumes
- Networks
- Registries
