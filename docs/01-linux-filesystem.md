# Module 01 - Linux Filesystem

## Objective

Understand the Linux filesystem hierarchy and learn how to navigate, inspect and manage files and directories in a professional Linux environment.

---

## Learning Outcomes

After completing this module you will be able to:

- Understand the Linux directory hierarchy.
- Navigate the filesystem efficiently.
- Create, copy, move and delete files.
- Inspect file metadata.
- Understand absolute and relative paths.

---

## Topics

- Filesystem Hierarchy Standard (FHS)
- Absolute vs Relative Paths
- Directory Structure
- File Management
- Basic Linux Commands
