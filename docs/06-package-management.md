# Module 06 - Package Management

## Objective

Understand how software packages are installed, updated, verified and removed in Ubuntu systems while maintaining a secure and stable environment.

---

## Learning Outcomes

After completing this module you will be able to:

- Manage software repositories.
- Install and remove packages.
- Update installed software.
- Verify package information.
- Understand package dependencies.

---

## Topics

- APT
- DPKG
- Repositories
- Dependencies
- Package Cache
- Software Updates

---

## Common Commands

```bash
apt update
apt upgrade
apt install
apt remove
apt purge
apt search
apt show
apt-cache policy
dpkg -l
```

---

## Security Perspective

Keeping software updated is one of the most effective controls against known vulnerabilities.
