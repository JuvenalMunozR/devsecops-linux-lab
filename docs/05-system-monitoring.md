# Module 05 - System Monitoring

## Objective

Monitor Linux systems to evaluate health, availability and performance.

---

## Learning Outcomes

After completing this module you will be able to:

- Monitor CPU usage.
- Monitor memory.
- Monitor storage.
- Review system logs.
- Detect abnormal behavior.

---

## Topics

- CPU
- Memory
- Storage
- Logs
- Uptime
- Performance metrics

---
