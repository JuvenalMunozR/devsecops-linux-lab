# Module 10 - Docker Networking

## Objective

Understand Docker networking models and communication between containers in isolated environments.

---

## Learning Outcomes

After completing this module you will be able to:

- Understand Docker bridge networking.
- Inspect Docker networks.
- Connect containers to custom networks.
- Publish container ports.
- Troubleshoot container connectivity.

---

## Topics

- Bridge Networks
- Host Network
- None Network
- Port Mapping
- DNS Resolution
- Container Communication

---

## Common Commands

```bash
docker network ls
docker network inspect
docker network create
docker network connect
docker network disconnect
docker run -p
docker port
```

---

## Security Perspective

Correct network segmentation reduces lateral movement and limits container exposure.
