# Module 09 - Docker Foundations Completion Report

## Module Objective

Learn the fundamental concepts of Docker and containerized environments.

## Activities Completed

* Installed and validated Docker integration with WSL2
* Pulled Docker images from Docker Hub
* Created and managed containers
* Explored the container lifecycle
* Used Docker volumes for persistent storage
* Validated data persistence across containers
* Created a Dockerfile and built a custom image

## Commands Practiced

```bash
docker pull
docker images
docker run
docker start
docker exec
docker ps
docker volume create
docker volume ls
docker build
```

## Key Learnings

* Images are immutable templates.
* Containers are runtime instances of images.
* Volumes persist data independently of containers.
* Dockerfiles enable reproducible image creation.
* Containers provide isolated execution environments.
